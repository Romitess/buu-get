## สรุปผล

ทีมได้จัดทำชุดทดสอบอัตโนมัติครอบคลุมเส้นทางธุรกิจหลักของระบบแล้ว:

**เข้าสู่ระบบ → ลงทะเบียน/ชำระเงิน → จัดการสอบ → คะแนน/ใบรับรอง → โปรไฟล์ → รายงานผู้บริหาร**

| รายการ | จำนวน |
|---|---:|
| เคสทดสอบที่ใช้งาน (Unit + Integration + E2E) | **709** |
| Unit | 400 |
| Integration (API) | 237 |
| E2E (UI) | 72 |
| บั๊กที่พบและบันทึกไว้ (ยังไม่แก้ในโค้ดผลิต) | 12 |

**นโยบาย:** เมื่อพบบั๊กในระบบจริง จะบันทึกใน Bug Log และข้ามเคสที่เกี่ยวข้อง — ไม่แก้ production เพื่อให้เทสผ่านอย่างเดียว

**ขอบเขตที่ยังไม่ทำในรอบนี้:** โมดูล ThaiD ทั้งก้อน · Moodle sync · Page builder · Platform gateway (ชุดเต็ม)

## บั๊กที่ควรแก้ก่อน (ผลกระทบสูง)

1. **BUG-004** — หน้าตรวจใบรับรองสาธารณะ (public verify) แสดงไม่พบเอกสาร  
2. **BUG-005** — กระทบยอดธนาคารเมื่อจับคู่ใหม่ ความสัมพันธ์ธุรกรรมอาจค้างผิดรายการ  
3. **BUG-010** — หน้าคะแนนโหลดช้าเมื่อข้อมูลเยอะ กระทบงาน import/ออกใบรับรอง  
4. **BUG-011** — ผู้ใช้ที่ล็อกอินแล้วสามารถแก้ไขโปรไฟล์ของคนอื่นได้หากรู้ id  
5. **BUG-008/009** — แอดมินเปิดแก้ไขสอบ/จัดการที่นั่งแล้วถูกพากลับหน้ารายการ

รายละเอียดครบ: `tests/BUG_LOG.md`
