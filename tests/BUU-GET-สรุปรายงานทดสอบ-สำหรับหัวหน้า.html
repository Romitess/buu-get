2. ความครอบคลุมตาม Flow

Flow ผลทดสอบ ความเสี่ยงที่ยังเปิด
1. เข้าสู่ระบบ / สิทธิ์ U114 · I58 · E10 หน้าตรวจใบรับรองสาธารณะใช้ไม่ได้ (BUG-004)
2. ชำระเงิน / ใบเสร็จ / กระทบยอด U141 · I65 · E15 กระทบยอด rematch ค้าง TRANX_ID เดิม (BUG-005)
3. ลงทะเบียน / voucher / แหล่งทุน U100 · I40 · E13 ที่นั่ง/เช็คชื่อบน UI มีปัญหาบางเคส (BUG-006/007)
4. วงจรชีวิตการสอบ U28 · I19 · E2 (+ข้าม 4) หน้าแก้ไขสอบ/ที่นั่ง redirect กลับ (BUG-008/009)
5. คะแนน / ใบรับรอง U47 · I25 · E8 path ใบรับรองซ้ำ / หน้าคะแนนโหลดช้า (BUG-002/010)
6. โปรไฟล์ / รูป / ประวัติ U21 · I17 · E5 สิทธิ์แก้ไข/อ่านโปรไฟล์คนอื่นหลวม (BUG-011/012)
7. รายงานสอบ (ผู้บริหาร) U11 · I8 · E3 ตัวกรองเดือน/รอบยังไม่ทำงานใน service

3. บั๊กที่ควรแก้ก่อน (ผลกระทบสูง)

  1. BUG-004 — หน้าตรวจใบรับรองสาธารณะแสดงไม่พบเอกสาร
  2. BUG-005 — กระทบยอดธนาคารเมื่อจับคู่ใหม่ ความสัมพันธ์ธุรกรรมอาจค้างผิดรายการ
  3. BUG-010 — หน้าคะแนนโหลดช้าเมื่อข้อมูลเยอะ กระทบ import/ออกใบรับรอง
  4. BUG-011 — ผู้ใช้ที่ล็อกอินแล้วแก้ไขโปรไฟล์คนอื่นได้หากรู้ id
  5. BUG-008/009 — แอดมินเปิดแก้ไขสอบ/จัดการที่นั่งแล้วถูกพากลับหน้ารายการ

4. ข้อเสนอขั้นตอนถัดไป

  1. แก้บั๊กผลกระทบสูงด้านบน (verify สาธารณะ · กระทบยอด · authz โปรไฟล์ · หน้าคะแนน)
  2. ปลด skip ของ E2E วงจรชีวิตสอบหลังแก้ BUG-008/009
  3. ถ้าต้องการต่อ: ทำชุด ThaiD / Moodle / Page builder ตามแผนผลิตภัณฑ์
